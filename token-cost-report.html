Methodology & caveats

  • Sources. Every *.jsonl under ~/.claude/projects/c--Users-User-Downloads-benmark-stadium8-test2/, including each session's subagents/ folder. Messages are deduplicated by message id (2497 unique priced assistant messages from 143 files).
  • Pricing. Anthropic list rates, platform.claude.com/docs pricing, retrieved 2026-06-11. Per-message tokens split into input, output, cache-write 5-min, cache-write 1-hour, and cache-read, priced with the multipliers above, then summed per agent / story / epic.
  • Currency. 1 USD = 16.5576 ZAR (TradingEconomics mid-market, 2026-06-11). ZAR figures are USD × 16.5576; FX moves intraday so treat ZAR as indicative.
  • Build vs other. The four /start + /continue sessions (matching the timing log's "4 sessions") are the build; their main-loop messages are cross-epic foreground work and all count as build cost. All other sessions (pre-/start exploration, the claude-api lookup, the commit/push close-out, doc/report sessions including this one) are listed separately.
  • Epic / story attribution. Each sub-agent's epic & story come from the first user message in its transcript (storySlug: / "Epic N, Story M"); its model, time window and duration come from its message timestamps. Main-loop foreground cost is a single cross-epic bucket — it is not split per epic (the timing event log does not carry fine per-epic main-loop boundaries).
  • Timestamp-based timing. PLAN active time is from build-timing.jsonl. Per-epic durations are wall-clock windows spanning that epic's sub-agents (they include some idle, unlike the "active" PLAN figure) — the BUILD phase's resume events lack matching yields, so true per-epic active time is not recoverable from the log. Manual-QA waits cost nothing and are excluded.
  • Missing external sessions. Part of Epic 4 was run on Claude Web, which leaves no local transcript — that work is absent here, so the local Epic 4 figure (session 04260c45) understates Epic 4's true cost and duration.
  • Fast mode. Sampled messages show service_tier: standard, so Opus is priced at the standard $5/$25 rate; any Fast-Mode turns (which bill at $10/$50) would raise the true Opus cost.
  • Cache-write mix. Of 9,075,965 cache-write tokens, 1,821,090 are 1-hour TTL (priced 2× input) and 7,254,875 are 5-minute TTL (1.25× input). Claude Code mostly writes 1-hour cache, so cache cost here is higher than a flat 5-minute estimate.
  • Supersedes the partial hook report. The repo's hook-based token-report.md only captured 340 responses through 2026-06-09 11:37 (the tracker stopped firing after the first BUILD story, ~24.9M tokens / $22.86). This report re-parses the full transcript history (2,497 messages, 226,833,507 tokens) and is the complete picture.

Time-vs-cost takeaways: sub-agents run concurrently (developer + code-reviewer + playwright-runner in parallel), so wall-clock is far shorter than summed agent time at the same token cost — the swarm buys speed for free. Idle gaps between turns (user decisions, manual QA) add wall-clock but zero tokens, so cost-per-active-minute is the honest efficiency measure.
